### Protagonist Labs

Small Windows apps that each do one job properly. Free ones are open source, with no account, no ads and no telemetry.
Everything is on **[protagonistlabs.app](https://protagonistlabs.app/?utm_source=github&utm_medium=profile&utm_campaign=profile)**.

**Free and open source**

- [SpaceScan](https://protagonistlabs.app/spacescan/?utm_source=github&utm_medium=profile&utm_campaign=profile): see what is filling up a drive; reads the NTFS MFT, so a whole drive maps in seconds. [source](https://github.com/limburatorul/spacescan)
- [Backup Labs](https://protagonistlabs.app/backuplabs/?utm_source=github&utm_medium=profile&utm_campaign=profile): incremental backups to an external drive, USB stick or NAS. [source](https://github.com/limburatorul/backup-labs)
- [File Labs](https://protagonistlabs.app/filelabs/?utm_source=github&utm_medium=profile&utm_campaign=profile): dual-pane file manager whose copies ask about every conflict once. [source](https://github.com/limburatorul/file-labs)
- [Sysoptimizer](https://protagonistlabs.app/sysoptimizer/?utm_source=github&utm_medium=profile&utm_campaign=profile): 17 Windows tweaks you can revert, plus cleanup and startup. [source](https://github.com/limburatorul/sysoptimizer)
- [HotkeyScan](https://protagonistlabs.app/hotkeyscan/?utm_source=github&utm_medium=profile&utm_campaign=profile): finds which program is holding a hotkey. [source](https://github.com/limburatorul/hotkeyscan)
- [Lume](https://protagonistlabs.app/lume/?utm_source=github&utm_medium=profile&utm_campaign=profile): keyboard launcher on Alt+Space, themed in plain CSS. [source](https://github.com/limburatorul/lume)
- [Auto Clicker](https://protagonistlabs.app/autoclicker/?utm_source=github&utm_medium=profile&utm_campaign=profile): hotkeys, point routes and scripts that wait for an image. [source](https://github.com/limburatorul/auto-clicker)
- [Cursor Selector](https://protagonistlabs.app/cursorselector/?utm_source=github&utm_medium=profile&utm_campaign=profile): preview and apply cursor schemes and packs. [source](https://github.com/limburatorul/cursor-selector)
- [SteamRadar](https://protagonistlabs.app/steamradar/?utm_source=github&utm_medium=profile&utm_campaign=profile): alerts when a Steam, GOG or Epic game goes free or under your price. [source](https://github.com/limburatorul/steamradar)
- [Glaze](https://protagonistlabs.app/glaze/?utm_source=github&utm_medium=profile&utm_campaign=profile): desktop player for YouTube without suggestions or comments, SponsorBlock built in (not affiliated with YouTube or Google). [source](https://github.com/limburatorul/glaze)

**Paid**

- [Shelf](https://protagonistlabs.app/shelf/?utm_source=github&utm_medium=profile&utm_campaign=profile): every PC game in one library, with saves backed up and disk space accounted for.
- [Frostpane](https://protagonistlabs.app/frostpane/?utm_source=github&utm_medium=profile&utm_campaign=profile): desktop icon panes with real blur over an animated wallpaper.
- [Reel](https://protagonistlabs.app/reel/?utm_source=github&utm_medium=profile&utm_campaign=profile): a movie and TV library for the folders you already have.
- [Stash](https://protagonistlabs.app/stash/?utm_source=github&utm_medium=profile&utm_campaign=profile): scheduled backups of Firefox and Thunderbird profiles.

Guides for Windows, PC games and backups: [protagonistlabs.app/guides](https://protagonistlabs.app/guides/?utm_source=github&utm_medium=profile&utm_campaign=profile)
